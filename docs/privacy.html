Privacy policy

still-life · effective 7 November 2026

still-life is an automated program (“the app”) run by the owner of the YouTube channel that hosts the still-life video. It turns comments on that video into cells in a Game of Life universe and shows the universe in the video's title and thumbnail. Its source code is public at github.com/davidackerman/still-life.

YouTube API Services

The app uses YouTube API Services. By using the app, including by commenting on the still-life video, you agree to be bound by the YouTube Terms of Service. Google's handling of your data is described in the Google Privacy Policy.

What the app accesses

  • The channel owner's account, with the owner's authorization: the still-life video's title, description, tags, category and language settings, so that it can change the title, the thumbnail and (optionally) a block in the description. When the universe dies, it also uploads an obituary video to the channel and makes the original video private.
  • Public comments on the still-life video: for each top-level comment, its ID, the author's channel ID (or display name if there is no channel ID), its text, and when it was published.

How it uses that data

  • The comment text is read once to work out which cells to add. The text is never stored.
  • The author's channel ID limits each channel to one injection per hour.
  • The comment ID makes sure a comment is processed only once.

Nothing else is done with it: no profiles, no advertising, no analytics, no selling or sharing with anyone.

What is stored, and for how long

  • Comment IDs and author channel IDs are stored only as keyed hashes (HMAC-SHA256 with a secret key), and are deleted after at most 72 hours.
  • The app keeps a permanent public log of the universe in the GitHub repository above. It contains only game data: the generation number, the time of each run, the parsed command (for example glider 10,20 se) and the cells it added. It contains no comment text, IDs, names, or anything else that identifies a commenter.
  • When the universe dies, the obituary video credits the last comment that changed the universe. To do that, the app looks the comment up on YouTube at that moment and may show the author's public display name in the video. If the comment has been deleted, no name is shown.

The repository is hosted by GitHub, whose own privacy statement covers that hosting.

Cookies and tracking

Neither the app nor these pages use cookies, trackers or third-party advertising.

Removing data and revoking access

Because nothing identifying is kept for more than 72 hours, there is normally nothing to remove. If you want something removed or have a question, open an issue at github.com/davidackerman/still-life/issues; requests are handled within 7 days.

The channel owner can revoke the app's access to their account at any time at security.google.com/settings/security/permissions.
