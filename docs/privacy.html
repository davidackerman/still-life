Privacy policy

still-life · effective 8 November 2026

still-life is a bot run by the owner of the still-life YouTube channel. It uses YouTube API Services; by using it you agree to the YouTube Terms of Service (see also the Google Privacy Policy).

It reads public comments on the video to turn them into cells. Comment text is never stored; comment and channel IDs are kept only as one-way hashes for up to 72 hours, then deleted. (The one exception is the channel owner's own pinned status comment, which the bot keeps up to date.) The public log holds game data only. If the universe dies, the obituary may show the display name of the last commenter who changed it.

No cookies, tracking, ads or sharing. Questions or removal requests: GitHub issues. The channel owner can revoke access here.
